# ВетКлиника 🐾

Учебный проект сайта ветеринарной клиники.

## Описание проекта
Сайт включает в себя:
- Главный экран с призывом к действию.
- Сетку интерактивных услуг (при клике на "Записаться" услуга автоматически подставляется в форму).
- Блок с врачами клиники.
- Форму записи с валидацией полей (имя, телефон, дата) на JavaScript.
- Адаптивную верстку (Grid/Flexbox) для мобильных устройств.

## Инструкция по локальному запуску
1. Склонируйте репозиторий или скачайте файлы.
2. Откройте файл `index.html` в любом современном браузере.
3. Для удобства разработки можно использовать расширение Live Server в VS Code.
